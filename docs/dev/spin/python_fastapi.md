# blue dev spin python-fastapi

Create a new FastAPI-based Python project.

## Usage

`blue dev spin python-fastapi --name=myproject --port=8000`

## Parameters

- `name` : The name of your project.  It will be used for the Project's name in the .toml file as well as the root folder name on the file system. **Default = myproject.**
- `port` : Sets the port for the server to start on. **Default = 8000.**
